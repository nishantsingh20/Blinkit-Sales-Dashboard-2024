### 📊 Key Metrics
- *Total Sales:* 1,202K
- *Average Sales:* 140.94
- *No. of Items:* 9K
- *Average Rating:* 3.97

### 🔍 Key Insights
- Tier 3 outlets generate highest sales (472K)
- Low Fat products dominate with 65% sales
- Top selling category: Fruits & Vegetables
- Outlet size: Medium performs best
